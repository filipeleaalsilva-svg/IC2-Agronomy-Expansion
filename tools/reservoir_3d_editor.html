Como Editar este Modelo

1. No Blockbench (Recomendado)

O Blockbench é a ferramenta oficial e gratuita para modelar Minecraft:

  1. Abra o Blockbench.
  2. Vá em File > Import > OBJ Model.
  3. Selecione o arquivo:
    models/block/agricultural_reservoir.obj
  4. Carregue as texturas da pasta:
    textures/blocks/water_tower_*.png

2. No Blender

No Blender, use File > Import > Wavefront (.obj) e selecione o arquivo com o material (.mtl) na mesma pasta.
